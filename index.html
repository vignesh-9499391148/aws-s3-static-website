Deployment Workflow

From HTML to the internet.

A simple overview of the deployment process for a static website.

STEP 01

Create

Build the HTML, CSS, and other static files required for the website.

STEP 02

Store

Upload the files to an Amazon S3 bucket with public access blocked.

STEP 03

Configure

Set up CloudFront, Origin Access Control, HTTPS, and the S3 bucket policy.

STEP 04

Validate

Open the CloudFront domain and test that the website loads successfully.

Security First

Designed with security in mind.

Access control

Keep the S3 bucket private and use a CloudFront Origin Access Control configuration to authorize access to website objects.

Security depends on the actual bucket policy, distribution configuration, and account permissions. Verify each before deployment.

Deployment checklist

  • Enable S3 Block Public Access.
  • Use HTTPS for website visitors.
  • Restrict S3 reads to the intended distribution.
  • Apply least-privilege permissions.
  • Check AWS costs and clean up unused resources.
